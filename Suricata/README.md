# Labo Suricata — Angry Poutine

Fichiers de départ du labo. L'énoncé donne les étapes à suivre.

- `labo.yaml` : réglages ajoutés à la configuration de Suricata.
- `regles/labo.rules` : le fichier où vous écrivez vos règles.
- `analyser.sh` : analyse la capture avec vos règles et résume les alertes.

La capture se trouve dans `../Exercice Angry Poutine/`. Elle contient un vrai maliciel Windows : travaillez uniquement dans votre VM Ubuntu du Cyber Range.
